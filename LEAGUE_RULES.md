# League rules

A 10-team Yahoo league with friends, 2026 season.

| | |
|---|---|
| Format | Head-to-head, categories |
| Draft | Live snake draft, March 21, 2026, 90 seconds per pick |
| Regular season | Weeks 1–22 |
| Playoffs | 6 teams, weeks 23–25 (ended September 20) |
| Trade deadline | August 6 |
| Waivers | FAAB, 2-day waiver period, 6 adds per week |
| Pitching minimum | 20 innings per week |

## Categories

**Hitting:** R, HR, RBI, SB, AVG, OPS
**Pitching:** W, SV, K, ERA, WHIP, QS

## Roster

C, 1B, 2B, 3B, SS, OF ×3, Util, SP ×4, RP ×3, P, Bench ×6, IL ×2

## How this shapes the tools

- **Quality starts count**, so the draft tool projects them. It's the
  one stat I added beyond Marcel.
- **Wins and saves count, but the draft tool doesn't project them.**
  Marcel doesn't, and I didn't want to invent a method. Closers are
  shown with their stats but get no score.
- **Head-to-head means a team's record depends on its weekly
  opponent.** The power rankings play every team against all nine
  others each week to separate record from luck.
